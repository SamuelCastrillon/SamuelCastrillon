### 🔭 Código abierto

**[OrbisPrismMCP](https://github.com/OrbisFactory/OrbisPrismMCP)** — Creador y mantenedor.

Una interfaz MCP asistida por IA para modding de Hytale. Descompone el JAR oficial
del servidor de Hytale, aísla su lógica principal y expone un servidor MCP para que
los desarrolladores consulten el código directamente desde sus herramientas de IA
(OpenCode, Cursor, VSCode, Antigravity, Gemini-CLI).

Construido con Python, MCP, Rich CLI y soporte bilingüe EN/ES. 4 ⭐
